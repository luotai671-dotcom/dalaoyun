CLIENT FAQ

高频疑难自检

排错时每次只改变一个设置，并记录修改前后的结果。订阅地址与 API Key 必须打码。

Windows 开启 TUN 后提示服务安装失败？

确认安装包来自官方发布页并校验签名，以管理员身份运行客户端后重新安装 Service Mode。若 Defender 明确误报，只允许已经核验的程序或目录，不要关闭整体防护；公司设备请联系管理员。

Shadowrocket 导入后测速全部 Timeout？

开启自动日期与时间，时钟偏差可能导致 TLS 握手失败。随后切换 Wi-Fi / 移动网络，长按订阅更新节点再测试。

macOS 终端 Git Clone 不走代理？

系统代理不会覆盖所有命令行程序。优先开启 Enhanced Mode / TUN；也可执行 git config --global http.proxy socks5://127.0.0.1:7897，不用时删除该配置。

Android 启动后国内 App 变慢？

确认模式为 Rule，并启用分应用绕行，将国内 App 排除。检查私人 DNS 是否与客户端 DNS 冲突。

多个平台同时使用为什么会断流？

套餐支持 3–5 台设备并发。超过限制可能触发临时限流，退出闲置设备或选择更多并发套餐。
