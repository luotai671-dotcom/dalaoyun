高频风控与连接排障

先固定地区、核验出口与 DNS，再处理浏览器或客户端配置。不要连续跨国切换账号。

为什么普通机房 IP 登录 Claude 充值后容易触发封控？

IDC ASN、共享地址的滥用历史，以及信用卡账单地区与节点归属地不一致都可能触发自动风控。原生住宅双 ISP 出口可以降低网络侧风险，但无法保证账号不被审核；应同时保持地区、设备、支付资料一致并遵守平台条款。

Cursor 或 VS Code 终端提示 AI 无法联网，如何配置？

在 Clash Verge Rev 安装服务模式并开启 TUN。虚拟网卡会接管系统 socket 数据包，再交给规则引擎匹配 AI 策略组，通常无需逐个终端设置 export https_proxy。启用后检查本地开发服务是否需要绕过。

ChatGPT 出现 Cloudflare 人机验证循环怎么办？

固定到纯净住宅节点，避免频繁切换国家；退出账号后清理 ChatGPT 与 Cloudflare 对应站点的 storage / cookies，关闭冲突代理扩展再登录。请正常完成人机验证，不要尝试绕过平台安全机制。

Shadowrocket 网页正常，但 ChatGPT App 无法连接？

确认全局路由为“配置”，AI 域名已指向住宅策略组；在配置中启用 Fake-IP 与可信 DoH，检查 UDP、IPv6 和系统 VPN 权限是否造成 DNS 旁路。修改后完全退出 App 再重新打开。
